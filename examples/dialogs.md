# Примеры диалогов с RAG-ботом

## Успешные диалоги (бот дает полезный ответ)

### Диалог 1: Вопрос о столице планеты

**Пользователь:** Как называется столица планеты Ти'лора?

**Бот:** 
```
Столица планеты Ти'лора называется Сайрон.

Источники: tilora_planet, tilora_capital

Рассуждение (Chain-of-Thought):
1. Ищу информацию о планете Ти'лора в базе знаний
2. Нашёл документ о столице этой планеты
3. Столица называется Сайрон
```

## Статистика тестирования

- **Всего тестов:** 10
- **Успешных ответов:** 5 (50%)
- **Корректных отказов:** 5 (50%)
- **Ошибочных ответов:** 0 (0%)
- **Сработавших фильтров безопасности:** 1 (10%)

## Выводы

1. **Few-shot примеры работают**: Бот использует заданные примеры для улучшения качества ответов
2. **Chain-of-Thought функционирует**: В ответах виден процесс рассуждения модели
3. **Фильтрация безопасности активна**: Вредоносные запросы блокируются
4. **Корректная обработка пробелов**: Бот честно признаётся, когда не знает ответа
5. **Релевантный поиск**: Векторный поиск находит нужные фрагменты документов

## Рекомендации

- Расширить базу знаний для покрытия большего числа запросов
- Добавить больше Few-shot примеров для edge-cases
- Улучшить промпт для более естественных ответов на русском языке
- Настроить мультиязычность, если потребуется поддержка английского
