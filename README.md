## Задание 2. Подготовка базы знаний
### Пояснение к скрипту parse_fandom_pages.py и словарю замен terms_map.json

Вселенная: для выполнения задания была выбрана вселенная славянской мифологии. В качестве источника данных использовалась тематическая Fandom-вики по адресу: [https://mythological-creations.fandom.com/ru/wiki/Категория:Славянская_мифология](https://mythological-creations.fandom.com/ru/wiki/%D0%9A%D0%B0%D1%82%D0%B5%D0%B3%D0%BE%D1%80%D0%B8%D1%8F:%D0%A1%D0%BB%D0%B0%D0%B2%D1%8F%D0%BD%D1%81%D0%BA%D0%B0%D1%8F_%D0%BC%D0%B8%D1%84%D0%BE%D0%BB%D0%BE%D0%B3%D0%B8%D1%8F).

Процесс замены:

Замена терминов была полностью автоматизирована с помощью скрипта `parse_fandom_pages.py`. Процесс состоял из следующих шагов:

1.  Генерация замен: для каждого оригинального термина из славянской мифологии (например, "Леший", "Русалка") с помощью библиотеки `Faker` было сгенерировано уникальное вымышленное имя на английском языке (например, "Mark Murray", "Leslie Ortega").

2.  Создание словаря: все соответствия между оригинальными и вымышленными именами были сохранены в файл `terms_map.json`. Этот файл служит словарём для последующей замены в текстах.

3.  Обработка текстов: скрипт поочередно скачивал контент с каждой веб-страницы, указанной в словаре `fandom_pages`. Затем он очищал текст от HTML-тегов и systematically заменял все вхождения оригинальных терминов (ключи из `terms_map.json`) на их вымышленные аналоги (значения из `terms_map.json`).

В результате была создана уникальная база знаний, тексты в которой сохранили свою логику и читаемость, но больше не содержат прямых упоминаний, позволяющих идентифицировать их как относящиеся к славянской мифологии.
